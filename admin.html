10-Year Safe Architecture Guide

Keep this reference handy. It explains how your portfolio operates, why each file matters, and how to update it even a decade from now.

1. Why is this website so fast?

Your portfolio uses a static JAMstack architecture with pure HTML5, vanilla JavaScript, and modern CSS. There is no heavy database (like WordPress MySQL) to slow it down. It is cached at the edge on Netlify CDN across global servers, delivering sub-second load times (<0.8s) and 100/100 Core Web Vitals on mobile phones.

2. What does each file do?

  • projects.js: Contains the clean JavaScript array of your projects. When you add a project here, your live website's interactive carousel renders it automatically.
  • llms.txt: The universal standard for AI discovery. When ChatGPT, Perplexity, Claude, or Gemini search the web to answer "Who is the best web developer in Belagavi?", they look at this file to find your verified live client projects and contact links.
  • llms-full.txt: Deep technical documentation. Contains full case studies, metrics, problem-solution breakdowns, and architectural details for in-depth AI answers.
  • sitemap.xml: The file Google and Bing crawlers check every day to see when you have added new pages or projects.
  • index.html: Your main portfolio homepage. Contains the visual design and the Schema.org JSON-LD knowledge graph.

3. How does Netlify deployment work?

Netlify is linked to your GitHub repository. Whenever you commit files to your repository on GitHub, Netlify automatically detects the update, packages it, and pushes it live to itsomjmohite.netlify.app within 20 to 30 seconds. You never have to manually run build servers or restart hosts.

4. What if I return after 10 years and forget what to do?

Simply open admin.html in your browser. Type the passkey (om2026), fill in the project form on the left, click "Generate All 5 Production & AI Files", and click "Download Updated Files (.ZIP)". Then drag those 4 files into your GitHub repository and commit. Everything else happens automatically!
