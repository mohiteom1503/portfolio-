Export & Publish Your Updates

Whenever you edit projects, prices, reviews, or your bio, choose either method below to deploy your changes to your live website:

Automated 1-Click Deploy to GitHub (Zero-Upload Method)

Enter your GitHub token once. Clicking "Deploy Directly" will commit your updated files straight to your GitHub repository in seconds, and Netlify will deploy live in ~20s!

Alternative: 30-Second Drag-and-Drop GitHub Upload
  1. Click the green "📦 Download Updated Files (.ZIP)" button above.
  2. Extract/unzip the file on your computer or phone.
  3. Open your portfolio repository on GitHub.com.
  4. Click Add file > Upload files and drag-and-drop the extracted files.
  5. Click the green Commit changes button.
✨ Netlify Auto-Deploy: Once committed to GitHub, Netlify automatically updates your live site at itsomjmohite.netlify.app in 20 seconds.
